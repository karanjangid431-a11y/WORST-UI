# 🤡 WORST-UI: The Ultimate Anti-Design & Dark UX Experience

A masterclass in user frustration and dark design patterns, featuring two distinct experiences:

1. **`index.html` - The Chaotic Rage-Bait UI ("World's Worst UI")**:
   - 💥 In-your-face sensory overload, neon color clashes, flashing alerts, clashing fonts.
   - 🏃 Runaway Submit button that dodges your cursor.
   - 🔊 Comprehensive synthesized Web Audio comedy sound system (farts, bonks, sad trombones, fahhh memes).
   - 🧩 Live mutating password requirements (must contain prime numbers, fruit names, no letter 'E', etc.).
   - 😈 Captcha from hell ("Click every square that contains vibes").
   - 📉 Progress bars that reach 99% then drop backward to 12%.
   - ⌨️ Typing sabotage (random letter swaps, cursor hopping).
   - 🤫 *Secret Escape*: Press the `Escape` key 3 times to toggle Calm Mode.

2. **`professional.html` - "Nimbus Workspace" (Subtle Corporate Gaslighting)**:
   - 👔 Looks indistinguishable from a sleek modern SaaS app (Stripe/Notion/Linear aesthetic).
   - 🔄 Upside-down navigation: Clicking *Projects* opens *Settings*, *Settings* opens *Billing*, *Billing* opens *Dashboard*, and *Dashboard* opens *Projects*.
   - ⏳ Polished micro-interactions that quietly waste time: fake 400ms route transitions, expiring 2FA countdowns, deceptive copy-to-clipboard buttons, and disappearing form fields.
   - 🤫 *Secret Escape*: Press the `Escape` key 3 times to enable Demo Mode (restoring normal navigation).

## 🚀 Live Demo & Deployment

This project is built with vanilla HTML, CSS, and modern JavaScript with zero build steps or dependencies.

### GitHub Pages Setup
To deploy this repository live on GitHub Pages:
1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then click **Save**.
4. Your site will be live at: `https://karanjangid431-a11y.github.io/WORST-UI/`
   - Chaotic UI: `https://karanjangid431-a11y.github.io/WORST-UI/`
   - Subtle SaaS UI: `https://karanjangid431-a11y.github.io/WORST-UI/professional.html`
